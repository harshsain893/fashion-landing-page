# Fashion Landing Page

A modern and minimal fashion landing page created as a mini learning project using HTML and CSS.  
The layout focuses on clean typography, CSS Grid positioning, and video integration.

## 🚀 Live Demo
👉 https://harshsain893.github.io/fashion-landing-page/

## 🛠️ Built With
- HTML5
- CSS3 (Grid Layout)
- Remix Icon
- Video Element

## 📌 Features
- CSS Grid based layout
- Modern fashion editorial design
- Video section integration
- Clean and minimal UI
- Responsive typography

## 📂 Project Structure
-index.html
-style.css
-video.mp4


## 🎯 Learning Outcome
- Understanding CSS Grid layouts
- Page structure and alignment
- Video handling in HTML
- Typography and spacing techniques
